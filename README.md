## Portfolio App

Una semplice applicazione portfolio creata con HTML, CSS e JavaScript puro che permette di:

### Funzionalità
1. **Area pubblica** - Visualizza i progetti in un layout a griglia responsive
2. **Area admin protetta** - Gestisci i progetti tramite un'interfaccia admin con password
3. **CRUD completo** - Aggiungi, modifica ed elimina progetti
4. **Persistenza dati** - Utilizza localStorage per salvare i progetti

### Come usare

1. Apri `index.html` in un browser web
2. I visitatori possono vedere i progetti nell'area pubblica
3. Clicca su "Area Admin" per accedere alla gestione
4. Usa la password: `admin123`
5. Nell'area admin puoi:
   - Aggiungere nuovi progetti con titolo, descrizione, immagine e link
   - Modificare progetti esistenti
   - Eliminare progetti

### Tecnologie
- HTML5
- CSS3 (con responsive design)
- JavaScript puro (Vanilla JS)
- localStorage per la persistenza dei dati
